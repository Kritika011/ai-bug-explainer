# 🐛 BugAI — AI Bug Explainer

An AI-powered debugging assistant that analyzes programming errors and explains the problem, root cause, solution, corrected code, prevention tips, and complexity.

Built with React, FastAPI, and Google Gemini.

---

## 🚀 Features

- 🤖 AI-powered bug analysis
- 🐛 Explains programming errors in simple language
- 🔍 Identifies the root cause
- 💡 Provides a solution
- ✅ Generates corrected code
- 🛡️ Provides prevention tips
- ⚡ Shows time complexity
- 💾 Shows space complexity
- 📋 Copy corrected code
- 🧪 Built-in example bug
- 📱 Responsive design
- 🌙 Modern developer-focused UI
